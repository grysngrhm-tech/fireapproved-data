# ORSC R327 local adoption

Municipalities that have adopted ORSC Section R327 (Oregon's dwelling
fire-hardening code section), from Oregon BCD's published list and from a city
ordinance where BCD has not yet listed the place. Status is adoption of the
code section, not a map of every tax lot.

- **Canonical page:** https://fireapproved.com/data/r327-adoption
- **Canonical JSON:** https://fireapproved.com/data/r327-adoption.json
- **Methodology:** https://fireapproved.com/methodology
- **Records:** 5 municipalities (cities and counties), each with the source
  document (BCD list entry or the ordinance itself) and adoption/effective
  dates where the source states them.
- **Files here:** `r327-adoption.json` (the JSON twin, verbatim) and
  `r327-adoption.csv` (the same rows as CSV; values unaltered).
